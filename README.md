# Responsive Portfolio Website Patrick

Современное адаптивное портфолио с темной темой, анимациями при прокрутке и функциональностью отправки email. Проект разработан с использованием методологии Mobile First.

## Описание

Полнофункциональное портфолио-сайт с красивым темным дизайном и плавными анимациями. Включает секции: главная, о себе, навыки, услуги, проекты и контакты. Проект использует ScrollReveal для анимаций и поддерживает отправку email через контактную форму.

## ✨ Особенности

- Полностью адаптивный дизайн (Mobile First)
- Темная цветовая схема с настраиваемыми цветами
- Плавная прокрутка между секциями
- Анимации при прокрутке (ScrollReveal)
- Функциональная контактная форма с отправкой email
- Современный и приятный пользовательский интерфейс
- Совместимость со всеми мобильными устройствами

## 🚀 Быстрый старт

## 🛠 Использование

### Настройка контента

Откройте `index.html` и заполните секции:

- **Header**: Навигационное меню
- **Home**: Главная секция с приветствием
- **About**: Информация о себе
- **Skills**: Ваши навыки
- **Services**: Предоставляемые услуги
- **Projects**: Портфолио проектов
- **Contact**: Контактная форма

### Настройка цветовой схемы

В файле `assets/css/styles.css` (строки 5-28) измените переменную `--hue`:

```css
:root {
  --hue: 162;  /* По умолчанию: зеленый */
  /* Orange: 14 | Blue: 210 | Pink: 356 | Purple: 250 */
}
```

### Настройка Email отправки

Для работы контактной формы необходимо настроить EmailJS:

1. Зарегистрируйтесь на [EmailJS](https://www.emailjs.com/)
2. Настройте сервис и шаблон
3. Добавьте скрипт EmailJS в `index.html`
4. Обновите `main.js` с вашими credentials
